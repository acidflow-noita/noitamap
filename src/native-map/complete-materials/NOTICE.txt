Standalone owned material-resolution component, ABI 3.

Derived from Lymm Telescope / pinned vitaminmoo source (MIT), Copyright (c)
2026 Lymm. The complete license is retained in LICENSE-telescope.txt.

Scalar kernels are copied from src/native-map/materials and the previously
validated task/native-wasm-topo0 prototype. The latter's arithmetic is retained;
only query-failure reason codes are added. complete.c combines their dispatch
with explicit host ownership and unresolved classifications. Seed preparation
copies bitmap_caves.js and surfaceNoisePhase with process-global seed caches,
diagnostic hooks and experimental global switches removed. Pinned default
arithmetic and RNG consumption remain unchanged.

No production import reaches Telescope, a renderer, network loading, a DOM
shim or a task directory. The caller compiles/delivers complete-materials.wasm,
then supplies seed, lattices, biome map, packed host chunks and material params.
Main-plane topology0 and topology2 are supported; vertical/local-grid behavior
preserves the existing topology2-only helper. Shafts precede host guards.
classifications distinguish resolved material, outside-plane air, forced air,
legacy host mode, unowned geometry, unknown biome, raw unsupported biome,
unsupported topology/configuration, out-of-table lookup and missing modifier.
All unresolved cases retain material -1. They require a caller-owned finishing
or fallback stage and must never be treated as resolved transparent pixels.

Known source limits: winter/_EMPTY_ omit runtime-RNG phase F; _EMPTY_ runtime
chunk changes are absent. The source seed-halving threshold and inside-noise
override are preserved. No independent game-pixel parity or instant-map claim.
Optional captured topology0 inputs can replace the owned seed grids explicitly.
Validated generationState also accepts the narrow named-grid interchange format
in ../game-state/. Missing imported winter/_EMPTY_ grids remain unresolved. Its
content digest must remain separate from seed-only map/cache identities. The
current source-parity scalar chain supplies the other deterministic inputs.
No real capture/exporter or end-user import UI is supplied by these APIs.

and the new game-state module/docs changed; every existing C/header/WASM hash
was checked against the preceding build identity before refreshing host hashes.
The unchanged166198-byte ABI3 WASM was not rebuilt. Synthetic import validation

Build (no compiler download):
  WASI_SDK_PATH=task/native-wasm-core/wasi-sdk-34.0-x86_64-linux \
    node src/native-map/complete-materials/build.mjs
Verify source/artifact identity:
  node src/native-map/complete-materials/build.mjs --check
Run real field, vertical, seed-grid and classification parity (Node 26):
  node src/native-map/complete-materials/parity.mjs

build-identity.json records compiler flags, local hashes, source provenance and
known limits. parity-result.json records the latest completed parity run. The
test uses existing reference fixtures only as an oracle; the runtime API has no
dependency on them. No memory growth occurs after resolver construction; result
arrays are borrowed until the next resolve on the same instance. All seed grids
belong to callers/resolvers, with no unbounded global cache.

engine-data.mjs is the owned static metadata copy, identical to the pinned
engine_data.js exports: material names/IDs, flat colors, biome records, WANG
sampling parameters and noise permutations. No runtime source imports.
selectBandPoints accepts biomeId/absolute x,y/density; the coverage variant
first runs the proven density function. computeMaterialNoiseDensityPoints
exposes that exact f32 density operation separately for scene preparation.
These methods accept at most 4096 points; their borrowed output storage is
shared between band and density queries. Band no-match remains -1.
Explicit band density must already be an exact f32 value, as produced by the
owned density query. Non-f32 values are rejected instead of silently changing
a caller's threshold comparison by narrowing its input.
