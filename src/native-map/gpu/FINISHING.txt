Owned runtime GPU finishing

composition-compute.ts: integer straight-alpha composition of original terrain,
ordered liquid corrections, all scene backgrounds then scene foreground/erase,
ordered decals, separate static air/ordinary masks, and exact page reductions.
An optional resident legacy base-color field handles material classifications
that require the raw source-color path. Original material IDs remain unchanged
for edge and liquid decisions; only owned foreground pixels consume this color.
Textures are original authored assets. Scene/color data is for the requested seed.
No final-terrain permutation library or persistent seed history is required.

edge-compute.mjs / edge-shader.mjs: GPU compute port of ../edges/core.c,
derived from Lymm Telescope under MIT; retain LICENSE-telescope.txt.
The CPU prepares exact ray sample indices, angular decisions and integer random
thresholds from the existing runtime tables. Each fixed-material phase selects
the first valid non-overwriting stamp or last overwriting stamp at a destination,
then resolves its color separately. Generation, seam and ordered scene mutation
phases retain the reference order. Transparent colored texels consume the
first-painted flag even when their alpha is zero. Material and RGBA outputs are
byte-exact against the owned C/WASM core in the tested fixtures.
Winner resolution and reset visit only touched destinations, using a GPU work
list and indirect dispatch. Seam candidates use disjoint bands; scene candidates
use exact interior bounds. Whole-scene edge eligibility is preserved before
clipping. Resident scene inputs are clip-copied on GPU in a separate pass, keeping
the main kernel within eight storage bindings. Composition borrows the resident
scene buffer until the caller's submission completes; it never owns that input.

These kernels are used by the experimental ?native=1 worker runtime; the ordinary
route is unchanged. completed-map-read.ts reads only completed pixels/mips for
the existing canvas presentation. coarse-map.ts joins finished page mips into
a small overview; no procedural generation runs during pan/zoom.
Callers supply an initialized GPUDevice and explicit resources, reuse pipelines,
retain original materials for composition, and fence before retiring inputs.
Edges mutate their own material input. Final RGBA uses little-endian packed
words (R in the low byte), with no hardware blending or color conversion.
Page bounds and local ray arithmetic remain canonical; merging pages into one
large edge canvas is not equivalent. Current page capacity is640x640 including
the halo. Page-level mips are complete; whole-world joins remain the caller's job.
