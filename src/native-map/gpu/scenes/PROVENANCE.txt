Exact runtime scene preparation

Promoted unchanged algorithms from the validated native GPU prototype. Scene
semantics derive from composition/prepare-scenes.ts, with its Lymm Telescope
(MIT) and native compositor (GPL-3.0) attribution in composition/NOTICE.txt.
The shared materials/band-kernel.mjs supplies certified interval band selection;
uncertain points are repaired by the caller's exact band resolver before ready.

scene-compute.ts exposes createGpuScenePreparer and preserves original-art LRU,
ordered substitutions, exact RGBA/erase/sourceAlpha, signed grids, art masking
and optional whole-scene edge eligibility. Completed scene buffers stay on GPU.
Only compact numerical-repair indices return to the CPU. Resources and output
ownership are explicit; batch.destroy follows the final GPU consumer fence.
No per-position permutation or persistent seed-result cache is used.

Native evidence:100Mines scenes across2seeds and164selected instances covering
all144authored source keys/all9regions; zero pixel, grid, mask, eligibility or
background differences. Supplementary alpha/clip/order cases also passed.
Source-art cache remains bounded through eviction, re-decoding and seed change.
These are native Dawn/llvmpipe checks, not browser or hardware speed claims.

This production module uses browser WebGPU and ../buffers.ts only; no Dawn,
Node module, test fixture or scratch-runtime import is included.
