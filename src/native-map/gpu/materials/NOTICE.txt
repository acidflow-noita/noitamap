Certified material GPU runtime, ABI3 correction module.

Promoted from the validated native implementation in task/native-biome-runtime/
gpu-materials. promotion.json records the original and promoted source hashes;
validated-scratch-identity.json preserves the preceding validation identity.
Only module/include paths, descriptive comments and error wording changed during
promotion. All WGSL arithmetic, scalar C kernels and correct.wasm bytes remain
unchanged. The MIT-attributed Telescope-derived material/noise logic retains
LICENSE-telescope.txt and the owned complete-materials source dependency.

Runtime modules import only owned browser-safe source. They do not import Dawn,
Node, filesystem/network loaders, browser automation, or task files. The caller
supplies a GPUDevice, CompleteMaterialInputs and compiled WebAssembly.Module.
Build.mjs is a separate Node-only build/identity utility, never a runtime import.

Entry: certified-engine.ts or index.ts
  prepareCertifiedMaterialSetup(device)
  createCertifiedMaterialEngine(device,input,{correctionModule,legacy?,diagnostics?})
The engine provides resolvePage/resolveRect, resolveExactRect, exact band point
helpers, axisCacheStatistics and destroy. Readiness includes every compact exact
repair. Original materials remain signed i32, including host-policy=-1 values.
Optional legacyColorBuffer is packed RGBA with Rlow, populated only after exact
classification3..7 and original legacy color resolution. Empty color results
retain no buffer. Destroy each returned field after GPU consumers finish.

The correction binary is an ordinary Vite asset:
  import correctionURL from './correct.wasm?url';
The caller fetches/compiles that URL and passes the module. This component does
not create an adapter/device or fetch assets. gpu/buffers.ts supplies browser-safe
upload/readback helpers shared with scenes.

The64MiBcharged device-local CPU cache stores requested1Daxis vectors only.
Immutable axes survive seed changes; cave/state vectors are scoped to an exact
engine and discarded on destroy. No seed-result/image/permutation cache exists.

Evidence remains in the scratch validation reports identified by promotion.json:
full two-seed all-nine material/page validation, exact legacy shaft checks,
sampler boundary cases, and9,322full-axis byte comparisons against the archived
uncached implementation. CERTIFICATE.txt describes conservative numerical bounds.
These establish parity with the owned source, not independent whole-game capture
fidelity or browser/hardware speed.64-column NG+/nightmare inputs are not admitted.
Default and captured cave-state limitations are unchanged.

Verify:
  node src/native-map/gpu/materials/build.mjs --check
Rebuild with an already installed compiler:
  WASI_SDK_PATH=/path/to/wasi-sdk node src/native-map/gpu/materials/build.mjs
No compiler download is performed by this utility.
